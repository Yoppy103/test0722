# 出力例（モックサーバでの実行結果）

トライアル環境の払い出し前に、`./scripts/run_all_mock.sh` をモックサーバ相手に
実行して得られた出力。**スクリプトが実際に通しで動作することの確認と、
納品されるレポートの体裁を事前に見てもらうためのもの。**

> ここの数値はモックサーバ（ローカル、疑似レイテンシ25ms）に対するものであり、
> スマレジ / Bカートの実環境の性能を示すものではない。

| ファイル | 内容 |
|---|---|
| `REPORT.md` | 正常系（すべて OK）の集計レポート |
| `REPORT_制約あり時.md` | スマレジが顧客グループ別価格に非対応だった場合のレポート |
| `probe_result.md` | API 能力調査の出力例 |
| `api_trace_抜粋.jsonl` | 通信ログの形式（資格情報がマスクされることの確認） |

`REPORT_制約あり時.md` は、`MOCK_SMAREGI_GROUP_PRICE=off` で
「会員ごとの価格を持てない」環境を再現したもの。この場合スクリプトは
同一エラーの連続を検知して早期に中断し、`--no-group` での切り分けを促す。
